          First-time setup
          
    Set up Ollama for BrowserChat
    
        
    
        
      
    
      
    
        
    
          Run AI models locally, then chat with them from this extension.
          
    Ollama must be installed, a chat model must be downloaded, and its local server must allow requests from Chrome extensions.
    
        
    
        
      
          
    1. 
            
      1
      
            
      
              
      Install Ollama
      
              
      Download the installer for macOS, Windows, or Linux, finish installation, and open Ollama once.
      
              Download Ollama
            
      
          
      2. 
          
    2. 
            
      2
      
            
      
              
      Download a chat model
      
              
      In Terminal, pull one model. Smaller models are faster and use less memory.
      
              
              
      BrowserChat works with Ollama chat models. Our first suggestion is gemma4:e4b; other good starting points include qwen3:4b, gemma3:4b, and llama3.2:3b. Vision features require a vision-capable model.
      
            
      
          
      3. 
          
    3. 
            
      3
      
            
      
              
      Allow browser communication
      
              
      Quit any Ollama server already running, then start it from Terminal with extension origins enabled. Keep this Terminal window open.
      
              
            
      
          
      4. 
          
    4. 
            
      4
      
            
      
              
      Return and connect
      
              
      Come back to BrowserChat and check again. Your downloaded models will appear in the model picker.
      
              
              
      
            
      
          
      5. 
        
    
        
    
          Still not connecting?
          
      
            
    • Make sure another Ollama process is not already using port 11434.
      • 
            
    • An HTTP 403 usually means Ollama was started without the OLLAMA_ORIGINS setting above.
      • 
            
    • If a model is missing, run ollama list to confirm it finished downloading.
      • 
            
    • If chat stopped working after it worked before, restart the server and check again here.
